# Herdr plugins

Before working on these plugins, read the [Herdr agent guide](https://herdr.dev/agent-guide.md).
Use the [official documentation](https://herdr.dev/docs/) to verify Herdr behavior.

Before reporting a plugin source change done, rebuild any generated executable it affects
using the applicable manifest `[[build]]` command(s). Tests and debug builds may not update
the artifact used by a locally linked plugin.
