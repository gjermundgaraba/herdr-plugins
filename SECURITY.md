# Security policy

Security fixes are made on `main`; older revisions are not supported.

Do not open a public issue for a suspected vulnerability. Report it through
[GitHub private vulnerability reporting](https://github.com/gjermundgaraba/herdr-plugins/security/advisories/new)
with the affected plugin, impact, and reproduction steps.

Reports involving Herdr Hub's per-user socket and SSH relays, or file
permissions on either, are especially important.
